**YouTube Offline Downloader**

Want to watch YouTube videos offline without having to buy Youtube Premium? Here's the solution ; an easy-to-make YouTube Offline Downloader.  All you need to do is follow these simple steps:
1. Import yt_dlp
2. Ask the user for a YouTube URL
3. Create a hashmap with "outtmpl" as the key and the path to the folder you want the videos to be downloaded in as the value.
4. Use the hashmap and the url with yt_dlp functions (as shown in YOUTUBE_DOWNLOADER.py) to access the YouTube video and download it in your folder.
